ShopBack - Your One-Stop Online Shopping Destination

Welcome to **ShopBack**, a modern and responsive e-commerce web application inspired by Flipkart!  
ShopBack aims to provide a seamless and enjoyable online shopping experience with a user-friendly interface, robust product catalog, and secure checkout process.



 Key Features

-**User Authentication:** Secure sign-up, login, and profile management.
- **Product Browsing:** Browse and search through a wide range of categories and products.
- **Product Details:** View detailed product descriptions, images, pricing, and customer reviews.
- **Shopping Cart:** Add, update, and remove products from the cart with ease.
- **Checkout & Payment:** Smooth and secure checkout process supporting multiple payment options.
- **Order Tracking:** Track your orders and view order history.
- **Responsive Design:** Fully responsive UI optimized for desktops, tablets, and mobiles.

---

 🛠️ Technologies Used

- Frontend: HTML5, CSS3, JavaScript ,Bootstrap
- Backend: Python, Django 
- Database: MySQL lite
- Authentication: Manual
